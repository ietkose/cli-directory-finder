## 🇬🇧 ENGLISH

**Directory Finder** is a fast, lightweight, and interactive command-line utility built to search, filter, and map file structures and directories seamlessly directly from your terminal.

### 🌟 Key Features
* **Fast Search**: Search for files and folders instantly across deep nested directories.
* **Flexible Filtering**: Filter by file extension, pattern, or depth level.
* **Interactive Terminal Output**: Clean, highlighted, and easy-to-read tree/directory structure display.
* **Lightweight**: Minimal external dependencies, built for speed and developer efficiency.

---

### 🌟 Tech Stack
* **Language:** Go (Golang 1.20+)
* **Core Packages:** `os`, `path/filepath`, `flag`, `fmt`

---

### 🌟 Quick Start & Usage

#### 1. Clone the Repository
```bash
git clone [https://github.com/ietkose/cli-directory-finder.git](https://github.com/ietkose/directory-finder.git)
cd directory-finder
```

2. Run the Tool
```bash
# Search in current directory
go run dizin_bulucu.go
```
```bash
# Search in a specific path or extension
go run dizin_bulucu.go --path /path/to/dir --ext .go
```

## 🇹🇷 TÜRKÇE
**Dizin Bulucu**, terminal üzerinden dizinleri, dosyaları ve klasör hiyerarşilerini hızlıca aramanızı, filtrelemenizi ve listelemenizi sağlayan hafif ve etkileşimli bir komut satırı aracıdır.

### 🌟 Öne Çıkan Özellikler
* **Hızlı Arama:** Derin klasör hiyerarşilerinde dosyaları ve klasörleri anında bulun.
* **Esnek Filtreleme:** Dosya uzantısına, isme veya derinlik seviyesine göre filtreleme.
* **Okunabilir Terminal Çıktısı:** Temiz, renkli ve ağaç (tree) yapısında dizin görünümü.
* **Hafif ve Hızlı:** Gereksiz bağımlılıklardan arındırılmış, geliştirici dostu yüksek performans.

### 🌟 Kullanılan Teknolojiler
* **Dil:** Go (Golang 1.20+)
* **Çekirdek Paketler:** `os`, `path/filepath`, `flag`, `fmt`

### 🌟 Kurulum ve Çalıştırma
1. Depoyu Klonlayın
```bash
git clone [https://github.com/ietkose/cli-directory-finder.git](https://github.com/ietkose/directory-finder.git)
cd directory-finder
```

2. Uygulamayı Başlatın
```bash
# Bulunduğunuz dizinde arama yapın
go run dizin_bulucu.go
```
```bash
# Belirli bir dizin veya uzantı için arama yapın
go run dizin_bulucu.go --path /path/to/dir --ext .go
```
